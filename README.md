## 作品亮点概览

### 新媒体产品与用户体验

`她健康` 和 `日落补给站` 是较完整的新媒体产品设计案例。前者围绕女性健康信息获取、状态记录、知识库、自测与社区支持展开，体现了健康传播、用户陪伴和信息可视化思路；后者结合场景体验、界面设计、空间动线、动态海报、路牌和 IP 形象，呈现出从线上产品到线下展陈的整体设计能力。

### AIGC 与内容生产

`aigc ip设计`、`aigc古诗视频制作` 和数字营销传播课程中的 AIGC 五一营销材料，体现了使用 AIGC 进行视觉生成、短片制作、海报设计和营销创意落地的实践过程。

### 数字营销与品牌传播

数字营销传播课程文件夹中包含营销策划案、媒介传播计划、毕业展营销策略和 PPT 优化材料；`三九胃泰` 则偏向品牌比赛或品牌传播提交材料，包含平面、视频、音频和报名文档。

### 数据可视化与公共议题

`原来也有人给我们撑腰` 聚焦女性背后的公益组织，通过文本、Notebook、HTML 和多组 SVG 图表呈现数据分析与信息可视化成果。`出差的“打工”熊猫` 则包含 Tableau 源文件和展示图，体现了数据叙事与可视化表达能力。

### 文旅与互动叙事

`梦回丝路` 包含 H5 二维码、展板、视频和研发说明，适合作为文旅传播、互动叙事或新媒体展示型作品查看。
